# Spanish alignment decoys: 297 source records

Download `spanish_decoys_297_complete.zip` for the complete package, including modified transcripts and JSON/CSV/Excel answer keys. The separate `answer_key.xlsx` and `decoy_corpus_ACTIVE_ONLY.json` are also available here.

There are 734 planted errors: 267 records have timing/transcript changes; 30 records without final word timings have synthetic-checkbox errors. All 297 are documented in the complete package. The template JSON contains only the 111 eligible records and supported error types. The remaining records and other error types remain in the full package.

The unchanged reference scorer passed all 734 decoy/reference checks. No matching audio was supplied, so actual audio timing, silence and clip duration were not independently verified. Refer to the package README and validation reports before import.

To download an individual file on GitHub, open it and click **Download raw file**. To download the repository, use **Code → Download ZIP**.
